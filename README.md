# Diabetes Risk Pattern Recognition System

> **Academic Project** for the subject **Pattern Recognition (PR)**  
> **Topic**: Develop a PR System to Classify Individuals as Diabetic or Non-Diabetic Using Relevant Clinical Parameters and Evaluate Classification Performance.

---

## ⚠️ Academic Disclaimer

> **IMPORTANT**: This project is developed for academic and educational purposes only. It is **not** a medical diagnostic tool. Predictions generated by the machine learning models should not be used as a substitute for professional medical advice, diagnosis, or treatment.

---

## 1. Project Objective

The objective of this project is to design and implement a machine learning-based **Pattern Recognition System** that classifies individuals as either **Diabetic (1)** or **Non-Diabetic (0)** based on relevant clinical parameters.

The system demonstrates the complete Pattern Recognition engineering pipeline:
$$\text{Dataset} \rightarrow \text{Data Preprocessing} \rightarrow \text{Feature Selection} \rightarrow \text{Model Training} \rightarrow \text{Classification} \rightarrow \text{Performance Evaluation} \rightarrow \text{Prediction}$$

---

## 2. Dataset Description

The system uses the benchmark **Pima Indians Diabetes Dataset** (768 female patient records).

### Features (8 Clinical Parameters):
1. **Pregnancies**: Number of times pregnant (`count`)
2. **Glucose**: 2-hour plasma glucose concentration (`mg/dL`)
3. **BloodPressure**: Diastolic blood pressure (`mmHg`)
4. **SkinThickness**: Triceps skin fold thickness (`mm`)
5. **Insulin**: 2-Hour serum insulin (`mu U/ml`)
6. **BMI**: Body Mass Index ($\text{weight in kg} / (\text{height in m})^2$)
7. **DiabetesPedigreeFunction**: Diabetes pedigree score based on genetic family history
8. **Age**: Age in years

### Target Variable:
- **Outcome**: `0` = Non-Diabetic (500 samples, 65.1%), `1` = Diabetic (268 samples, 34.9%)

## 5. Machine Learning Classifiers

1. **Logistic Regression**: Linear probabilistic classifier estimating class probabilities via a sigmoid function.
2. **K-Nearest Neighbors (KNN)**: Non-parametric instance-based classifier assigning majority class of 5 nearest Euclidean neighbors.
3. **Decision Tree Classifier**: Non-linear rule-based tree splitting features on Gini impurity reduction (`max_depth=5`).
4. **Support Vector Machine (SVM)**: Maximum-margin kernel classifier using Radial Basis Function (RBF) kernel.

## 7. Installation & Setup Instructions

### Prerequisites:
- Python 3.10+
- Node.js v18+ & npm

### Step 1: Clone Repository & Setup Backend

```bash
cd backend
python -m pip install -r requirements.txt
```

### Step 2: Train Models & Generate Metrics

```bash
python train_models.py
```

### Step 3: Run Backend REST API Server

```bash
python app.py
```
*Backend API will run on `http://localhost:5000`*

### Step 4: Setup & Run Frontend Web Application

Open a new terminal window:

```bash
cd frontend
npm install
npm run dev
```
*Frontend application will run on `http://localhost:5173`*

## 8. Backend API Documentation

- `GET /api/health`: Health status check
- `GET /api/dataset-summary`: Dataset records, zero counts, and feature summary statistics
- `GET /api/dataset-analysis`: Feature histograms & data sample preview
- `GET /api/models`: Model metadata and descriptions
- `GET /api/performance`: Computed evaluation metrics table
- `GET /api/confusion-matrix/<model_key>`: 2x2 confusion matrix (TN, FP, FN, TP) for specified classifier
- `GET /api/feature-importance`: Feature importances and standardized logistic coefficients
- `GET /api/correlation`: Pearson feature correlation matrix
- `POST /api/predict`: Runs clinical inputs through preprocessor and predicts outcome + model probability
